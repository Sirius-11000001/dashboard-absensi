## Kenapa kami menggunakan 2 web server?
Karna saya tidak mengerti cara menggunakan Xampp secara benar, jadi saya menggunakan 2 web server, yaitu Xampp dan Flask.

## Apa itu Flask?
Flask adalah sebuah framework Python yang digunakan untuk membuat aplikasi web. Flask adalah pilihan yang
baik untuk membuat aplikasi web yang sederhana dan cepat.

## Apa itu Xampp?
Xampp adalah sebuah aplikasi yang digunakan untuk membuat dan mengembangkan aplikasi web. 
Xampp adalah pilihan yang baik untuk membuat aplikasi web yang kompleks dan memerlukan database.

## Kenapa bahasa program utamanya menggunakan PHP?
Karna dalam tugas kali ini wajib dan diutamakan menggunakan PHP

## Kenapa Menggunakan Framework Bootstrap CSS?
- Dengan menggunakan Framework (Bootstrap) Membuat website yang tampilannya 
otomatis menyesuaikan dengan berbagai ukuran layar
- Membangun website lebih cepat karena banyak komponen yang sudah siap pakai.
- Desain yang konsisten di seluruh halaman website
Singkatnya Bootstrap adalah alat bantu yang sangat berguna bagi para developer
untuk membuat website yang modern, responsif, dan menarik secara visual.

## Kenapa Kami tidak menggunakan Framework (Flask dengan Tatanan yang benar?)
Pada awalnya kami berencana menggunakan basic struktural Flask pada aplikasi ini.
Namun, Ternyata kami tidak diperbolehkan menggunakan struktural Framework utuh di semester 3, jadi kami menggunakan Flask sebagai framework yang sederhana saja. Itulah mengapa kami tidak menggunakan struktur yang benar.
